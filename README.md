# Jeld

## What is Jeld?

__Jeld IS STILL WORK IN PROGRESS.__

Jeld is a small application to visualize personal finances: Keeping track of bank accounts, depots and everything in between.
It is build as a JavaFX desktop application and no data goes to any cloud! I try to support as many data formats as possible, first and foremost the widely-used CAMT format.
